# VisionTrack AI

VisionTrack AI is a real-time object detection and tracking project built using Python, OpenCV, and YOLO. It detects and tracks objects in a webcam feed or video, counts entries and exits, and alerts when objects enter a restricted zone.

## Features

- Real-time object detection
- Object tracking with unique IDs
- Entry and exit counting
- Restricted-zone alerts
- Live detection analytics
- Webcam and video-file support

## Technologies Used

- Python
- OpenCV
- Ultralytics YOLO
- ByteTrack
